# Виджет Go2Buy

Виджет в Maverick — это Go2Buy (`go2.by`): отдельный сайт продажи билетов и встраиваемый интерфейс, через который партнёрские площадки продают билеты mooon и Silver Screen.

<div markdown>
<strong>Для кого</strong>
Поддержка, менеджеры партнёров, технические специалисты, администраторы.
</div>
<div markdown>
<strong>Когда применяется</strong>
Когда нужно понять, где продаётся билет через `go2.by`, как пользователь попадает в покупку с партнёрской площадки или какой вариант встройки использован.
</div>
<div markdown>
<strong>Что получится</strong>

</div>

## Что входит в виджет

Go2Buy работает в двух ролях:

- как самостоятельный сайт `go2.by` с афишей, поиском билетов, пространствами и документами;
- как встроенный интерфейс на внешних площадках: в модальном окне, контейнере на странице или прямым переходом к выбору мест.

![Главная страница Go2Buy](assets/media/widget/live/go2-home.png)

## Где используется

Через виджет могут продаваться билеты на сайтах и сервисах партнёров:

- `relax.by`;
- `afisha.me`;
- `go2.by`;
- `kinoafisha.info`;
- `o!plati`;
- `bezkassira.by`;
- `onliner.by`;
- `tochka.by`;
- `palazzo.by`;
- `бизнес-среда`;
- `arena-city.by`;
- `afisha-by.online`;
- `minskcitymall.by/cinema`.

Для каждого партнёра важно смотреть фактическую точку входа: кнопка, время сеанса, блок `Билеты`, iframe-контейнер или ссылка на `go2.by`.

## Варианты размещения

| Вариант | Как выглядит для пользователя | Пример |
| --- | --- | --- |
| Самостоятельный сайт | Пользователь открывает `go2.by` и проходит путь покупки внутри Go2Buy. | `go2.by` |
| Прямой переход к залу | Партнёр показывает своё расписание, а клик по времени ведёт на `go2.by/hall`. | `relax.by` |
| Pop-up | На сайте партнёра открывается всплывающее окно с iframe Go2Buy. | `kinoafisha.info` |
| Контейнер на странице | Виджет встроен прямо в блок страницы партнёра. | `arena-city.by`, `minskcitymall.by/cinema` |

## Техническая идея

Виджет подключается через скрипт:

```html
<script src="https://go2.by/widget/ticketslab-widget.js"></script>
```

Скрипт создаёт глобальный объект `tlWidget`. Через него партнёр открывает виджет в модальном окне или встраивает его в подготовленный контейнер.

Подробности для технической интеграции см. в [принципах работы виджета](Виджет/Принципы%20работы%20виджета.md).

## Что важно контролировать

!!! warning "Важно"
    Виджет связан с оплатой, персональными данными и учётом продаж по партнёрам. При интеграции нужно указывать УНП партнёра (`partnerNIP`), иначе продажи могут попасть на УНП по умолчанию и вызвать ошибки в отчётах.

При разборе инцидентов по виджету фиксируй:

- где началась покупка: `go2.by` или конкретная партнёрская площадка;
- какой был сценарий: самостоятельный сайт, прямой переход, pop-up или контейнер;
- какой URL открылся после клика;
- есть ли в URL `showId`, `eventId`, `partnerNIP`;
- на каком шаге возникла проблема: выбор события, выбор сеанса, схема зала, email, оплата, получение билета.

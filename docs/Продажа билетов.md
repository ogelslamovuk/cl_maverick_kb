# Продажа билетов

Раздел для рабочих инструкций по продаже билетов и кассовым сценариям.

## Страницы

- [Базовая работа в Seller Web](Продажа%20билетов/Базовая%20работа%20в%20Seller%20Web.md) — базовый сценарий продажи билетов, товаров, комбо и сертификатов в Seller Web. Дублируется в отдельном разделе [Seller](Seller.md).
- [Возврат билетов](Продажа%20билетов/Возврат%20билетов.md) — публичные правила возврата по каналам покупки: касса, `mooon.by`, `go2.by`, события, промокоды, подарочные карты и сроки поступления денег.
- [Виджет](Виджет.md) — Go2Buy как самостоятельный сайт и встроенный сценарий покупки билетов на партнёрских площадках.
- [Массовая отмена сеансов и событий в Manager](Расписание%20и%20события/Массовая%20отмена%20сеансов%20и%20событий%20в%20Manager.md) — служебный процесс для отмены сеанса или события после старта интернет-продаж.

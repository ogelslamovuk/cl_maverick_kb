# Кассовые группы и классификация продуктов в Portal

Кассовая группа — папка, в которой товары отображаются на кассе. Например, группу `Кальян` можно поместить в `Бар`.

Portal → `каталог` → `Кассовые группы`.

## Создать или изменить кассовую группу

1. Нажмите **«Добавить кассовую группу»** либо карандаш в строке.
2. Заполните обязательные поля.
3. Для вложенной группы в `Choose owner` выберите родительскую группу.
4. Сохраните карточку.

`Choose owner` — это владелец (owner), то есть родительская кассовая группа.

![Выбор владельца кассовой группы](../assets/media/portal-catalog/cash-group-owner-selection.png)

!!! danger "Критическая проверка владельца"
    Не выбирайте редактируемую или создаваемую кассовую группу её собственным владельцем: ID владельца должен отличаться от ID группы. Самоссылка создаёт циклическую иерархию и рекурсию, что нарушает работу каталога.

    Для группы верхнего уровня владелец не выбран. Для `Кальяна` внутри бара владельцем будет `Бар`. Если самоссылка уже сохранена, не меняйте другие сущности каталога; передайте системному администратору название и ID группы, а также ID выбранного владельца.

Группу можно удалить, только если к ней не привязаны продукты.

## Остальные справочники

- Группа продуктов — верхний уровень классификации для отчётности.
- Категория продукта привязана к группе продуктов.
- Класс продукта привязан к типу продукта.
- Свойство и единица измерения выбираются в карточке товара.

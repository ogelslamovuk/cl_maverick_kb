# Решение проблем

Начни с поиска по тому, что видно на экране: названию кнопки, раздела, операции или сообщению об ошибке.

## Быстрый порядок

1. Найди инструкцию по операции через поиск.
2. Сверь объект, пользователя, дату и состояние операции.
3. Проверь раздел **Частые ошибки**, если он есть на странице.
4. Если проблема не решена, подготовь контекст и используй [SupportBot](SupportBot/Как%20пользоваться%20SupportBot.md).

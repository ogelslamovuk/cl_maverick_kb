# Массовая отмена сеансов и событий в Manager

Инструкция помогает отменить один сеанс или сеансы события, оформить возвраты по интернет-продажам, отправить гостям штатное уведомление и проверить результат.

<div class="kb-meta" markdown>
<div markdown>
<strong>Для кого</strong>
Репертуарный отдел и сотрудник, которому поручена отмена и доступен раздел «Массовые возвраты».
</div>
<div markdown>
<strong>Когда применяется</strong>
Когда отмена сеанса или события подтверждена: например, из-за форс-мажора, технической проблемы, недоступности зала или изменения проката.
</div>
<div markdown>
<strong>Что получится</strong>
Затронутые интернет-продажи перейдут в возврат, гостям уйдут уведомления, а отменённые сеансы будут сняты с публикации.
</div>
</div>

## Где находится

В Manager открой на левой панели **Массовые возвраты**.

- **Отмена сеанса** — работа с одним сеансом по его ID.
- **Отмена события** — работа с сеансами одного события, с ограничением по объекту и периоду.

## Перед началом

- Убедись, что решение об отмене подтверждено владельцем процесса.
- Определи объём операции: один сеанс или сеансы события за конкретный период.
- Для одного сеанса найди его ID в таблице **Сеансы** и проверь объект, зал, событие, дату и время начала.
- Для события найди ID в справочнике **События**.
- После поиска проверь количество билетов и разбивку по каналам: `Web`, `Widget`, `Seller`, `ATM`, `Manager`.
- Поле **Шаблон email** оставь со штатным значением `Отмена`. Подбор и изменение других шаблонов в этом процессе не описаны.
- До нажатия **Применить** сними все затронутые сеансы с публикации в **Расписании**.

![Таблица сеансов](../assets/media/manager/manager-mass-refunds-sessions-table.jpg)

## Отменить один сеанс

1. Открой **Сеансы**, найди нужный сеанс и скопируй его ID.
2. Перейди в **Массовые возвраты → Отмена сеанса**.
3. Введи ID и нажми **Найти сеанс**.
4. Проверь наименование, дату и время начала, общее количество билетов и разбивку по каналам продаж.

![Форма отмены сеанса](../assets/media/manager/manager-mass-refunds-session-form.jpg)

5. В **Расписании** сними найденный сеанс с публикации.
6. Вернись в форму отмены, нажми **Применить** и подтверди действие.
7. Дождись завершения обработки.

![Обработка отмены сеанса](../assets/media/manager/manager-mass-refunds-session-progress.jpg)

## Отменить событие

1. Открой **События**, найди нужное событие и скопируй его ID.
2. Перейди в **Массовые возвраты → Отмена события**.
3. Введи ID события.
4. Выбери объект. Если оставить это поле пустым, поиск включает сеансы события **по всем объектам**.
5. Нажми **Найти событие**.
6. Проверь событие, объект, период, количество билетов и разбивку по каналам.
7. Если отменяется не весь период, задай даты и время начала и окончания, затем нажми **Обновить**.

![Форма отмены события](../assets/media/manager/manager-mass-refunds-event-form.jpg)

8. В **Расписании** сними с публикации каждый сеанс, который попал в выбранный объект и период. Если объект не выбран, проверь расписание по всем объектам.
9. Вернись в форму, нажми **Применить** и подтверди действие.
10. Дождись завершения обработки.

![Обработка отмены события](../assets/media/manager/manager-mass-refunds-event-progress.jpg)

## Проверить результат

- Открой отменённый сеанс и перейди на вкладку **Детали сеанса**. Для обработанных интернет-продаж должны появиться строки с типом `возврат`.
- Проверь **Отчёт по отправленным email по возвратам**: по уведомлениям должен быть понятен статус отправки; ошибки зафиксируй для обработки по действующему регламенту.
- Проверь таблицу **Продажи**: по обработанным билетам должны быть связаны возвраты.
- Убедись, что сеанс снят с публикации и больше не доступен в затронутых каналах продаж.

![Детали сеанса после возврата](../assets/media/manager/manager-mass-refunds-session-details.jpg)

## Важно

!!! warning "Пустой объект — это все объекты"
    При отмене события пустое поле **Объект** не ограничивает выборку. До запуска проверь, какие площадки и сеансы попадут в операцию.

!!! warning "Операция связана с деньгами"
    Не запускай отмену без подтверждённого решения, проверки ID, объекта, периода, каналов продаж и снятия сеансов с публикации.

!!! warning "Не обещай возврат по каждому каналу"
    В записи подтверждена обработка продаж из `Web` и `Widget`. Значения `Seller`, `ATM` и `Manager` используй для контроля состава продаж; их обработку не считай частью этого сценария без отдельного регламента.

!!! warning "Не повторяй операцию вслепую"
    Если часть билетов не перешла в тип `возврат` или в отчёте есть ошибка email, сначала проверь детали сеанса, продажи и действующий порядок обработки ошибки.

## Частые ошибки

- Оставляют отменённый сеанс опубликованным.
- Вводят ID события вместо ID сеанса — или наоборот.
- Не ограничивают объект при отмене события и получают выборку по всем площадкам.
- Не проверяют период перед нажатием **Применить**.
- Не сверяют возвраты в деталях сеанса и статус отправки уведомлений.
